# Помощник Банка России по документам

## Что показать жюри за 3 минуты

1. Введите: «Мне нужно подготовить приказ о вводе информационной системы в эксплуатацию». Бот находит маршрут визирования, предлагает официальный модуль и либо выдаёт бланк, либо собирает черновик вопросами.
2. Загрузите намеренно незаполненный проект приказа. Проверка найдёт линии, квадратные скобки, служебные элементы и несоответствия оформления; затем покажет дальнейший порядок: визирование, подписание, регистрация.
3. Спросите про реестр замечаний: бот выдаёт структуру таблицы, но честно отмечает, если конкретное требование не найдено. Это защита от галлюцинаций.
4. Откройте `/admin`, загрузите новую редакцию документа и покажите, что она сразу появляется в составе базы. Включите «ИИ-режим»: ИИ лишь формулирует ответ по найденным пунктам и обязан проставить проверяемые ссылки.

## Попадание в задачу

| Требование | Реализация |
|---|---|
| Помочь решить рабочую задачу | распознавание намерения, уточняющие вопросы, готовый маршрут действий |
| Опираться на материалы | поиск по Инструкции, Матрице, методическим рекомендациям и модулям |
| Не выдумывать | порог релевантности; честный ответ «нет в базе»; проверка ссылок ИИ |
| Шаблоны и черновики | пошаговое заполнение модуля, бланк, копирование черновика |
| Проверка проекта | загрузка PDF/DOCX/TXT/MD, поиск незаполненных полей и элементов шаблона |
| Визирование | Матрица обязательного визирования плюс напоминание об общем маршруте |
| Администрирование | защищённая токеном загрузка и обновление базы без изменения кода |

## Запуск

Нужны Python 3.11+ и терминал в папке проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
$env:ADMIN_TOKEN = "придумайте-длинный-секрет"
uvicorn main:app --host 0.0.0.0 --port 8000
```

Откройте `http://127.0.0.1:8000`. Админка доступна по `http://127.0.0.1:8000/admin`; введите значение `ADMIN_TOKEN`, затем выберите файл. API-документация: `/docs`.

Для постоянного запуска на сервере задайте переменные окружения в панели хостинга, запускайте `uvicorn main:app --host 0.0.0.0 --port $PORT` и не публикуйте `.env`, ключи или папку с загруженными документами в публичном репозитории.

## ИИ-режим

ИИ-режим выключен, пока на сервере нет `OPENROUTER_API_KEY`. Укажите ключ только в секретах сервера (или в локальном `.env`), например:

```text
OPENROUTER_API_KEY=ваш_ключ
OPENROUTER_MODEL=qwen/qwen-2.5-72b-instruct
OPENROUTER_BASE_URL=https://openrouter.ai/api/v1
```

Ключ не передаётся браузеру, не записывается в журнал и не включён в этот проект. Даже в ИИ-режиме модель получает только найденные фрагменты базы и ответ отклоняется, если в нём нет ссылок на них. Без ключа сервис продолжает работать в детерминированном режиме цитат; можно использовать локальную модель Ollama.

## Карта кода

- `app/services/dialog.py` — основной сценарий: уточнение, поиск, шаблон, проверка и безопасный отказ.
- `app/services/kb.py` и `retrieval.py` — загрузка документов, нарезка на пункты и BM25-поиск.
- `app/services/checker.py` — прозрачные правила проверки проекта.
- `app/services/llm.py` — локальный Ollama и Qwen 2.5 через OpenRouter.
- `app/routers/admin.py` и `static/admin.html` — админка и загрузка базы.
- `knowledge_base/official_materials/` — исходные материалы организаторов; `official_digest.md` — аккуратно размеченные ключевые положения для точных источников.

## Важные ограничения для честной защиты

Сейчас доступ ролей и админ-токен — демонстрационная модель. В промышленной версии их нужно заменить интеграцией с SSO, журналированием в корпоративный контур, антивирусной проверкой загрузок и разграничением доступа к исходным документам. Приложение не подменяет юридическую или лингвистическую экспертизу и прямо сообщает о пробелах материалов.
